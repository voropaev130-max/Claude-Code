Реєстрація акаунту Anthropic

🎯 Що робимо

Створюємо акаунт на сайті Anthropic — це компанія, яка розробляє Claude.

🔗 Відкрити console.anthropic.com
  1. Відкрийте посилання вище — відкриється сторінка реєстрації Anthropic Console.
  2. Натисніть кнопку "Sign Up" (Зареєструватися). Можна увійти через Google-акаунт або ввести email та пароль.
  3. Підтвердіть email — перевірте пошту, знайдіть лист від Anthropic і натисніть кнопку підтвердження.
  4. Увійдіть у свій акаунт — після підтвердження ви потрапите в консоль Anthropic.
💡
Порада: Використовуйте робочу email-адресу вашої компанії, щоб потім легко об'єднати акаунти в одну організацію.

Встановлення Node.js

⚙️ Навіщо потрібен Node.js

Claude Code працює через npm — менеджер пакетів Node.js. Без Node.js встановити Claude Code неможливо.

💡
Потрібна версія: Node.js 18 або новіша (рекомендуємо LTS — Long Term Support).
💻 Windows
🍎 macOS
🐧 Linux

Встановлення на Windows

  1. Завантажте інсталятор Node.js:
    ⬇️ Завантажити Node.js (LTS)

    На сайті натисніть велику зелену кнопку "Download Node.js (LTS)".

  2. Запустіть завантажений файл (наприклад, node-v22.x.x-x64.msi).
  3. У вікні інсталятора:
    → Натисніть "Next"
    → Прийміть ліцензію (поставте галочку) → "Next"
    → Шлях залиште за замовчуванням → "Next"
    → Натисніть "Install"
    → Дочекайтесь завершення → "Finish"
  4. Перевірте встановлення. Відкрийте PowerShell (натисніть Win + X, оберіть "Terminal" або "PowerShell"):
    node --version

    Має показати щось типу v22.x.x

    npm --version

    Має показати щось типу 10.x.x

⚠️
Якщо команди не працюють — закрийте PowerShell і відкрийте заново. Інколи потрібно перезавантажити комп'ютер.

Встановлення на macOS

Варіант A: Через інсталятор (простіший)

  1. Завантажте інсталятор:
    ⬇️ Завантажити Node.js (LTS)

    Оберіть версію для macOS.

  2. Відкрийте завантажений .pkg файл і пройдіть інсталяцію (натискайте "Continue" → "Install").
  3. Перевірте в Terminal (натисніть Cmd + Пробіл, введіть "Terminal"):
    node --version

Варіант B: Через Homebrew (для досвідчених)

Terminal brew install node
💡
Немає Homebrew? Спочатку встановіть його командою:
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

Встановлення на Linux (Ubuntu/Debian)

Terminal # Оновити список пакетів sudo apt update # Встановити Node.js та npm sudo apt install -y nodejs npm # Перевірити версію node --version npm --version
💡
Якщо версія Node.js менша за 18, встановіть через NodeSource:
curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash - sudo apt install -y nodejs

Встановлення Claude Code

🚀 Встановлюємо Claude Code через npm

Тепер, коли Node.js є, встановлюємо сам Claude Code однією командою.

⚠️
Увага (Windows): Команди потрібно виконувати в PowerShell або Windows Terminal, запущеному від імені адміністратора.
Натисніть Win + X → виберіть "Terminal (Admin)" або "PowerShell (Admin)".
💻 Windows
🍎 macOS
🐧 Linux

Windows

  1. Відкрийте PowerShell від імені адміністратора (Win + X → "Terminal (Admin)")
  2. Виконайте команду встановлення:
    npm install -g @anthropic-ai/claude-code
  3. Дочекайтесь завершення. Ви побачите повідомлення про успішне встановлення.
  4. Перевірте, що Claude Code встановлено:
    claude --version

    Має показати номер версії, наприклад 1.x.x

macOS

  1. Відкрийте Terminal (Cmd + Пробіл → введіть "Terminal" → Enter)
  2. Виконайте команду встановлення:
    npm install -g @anthropic-ai/claude-code
  3. Якщо з'являється помилка з правами доступу, додайте sudo:
    sudo npm install -g @anthropic-ai/claude-code

    Введіть пароль від вашого Mac (символи не відображатимуться — це нормально).

  4. Перевірте:
    claude --version

Linux

  1. Відкрийте термінал
  2. Виконайте команду:
    sudo npm install -g @anthropic-ai/claude-code
  3. Перевірте:
    claude --version

Створення робочих папок

📁 Структура папок для роботи

Створимо зручну структуру папок, щоб усі проєкти були організовані.

📁 C:\Users\ВашеІмя\ (або /Users/ВашеІмя/ на Mac) 📂 claude-projects\ ← головна папка для всіх проєктів 📂 project-1\ ← перший проєкт 📂 project-2\ ← другий проєкт 📂 sandbox\ ← папка для тестів та експериментів
💻 Windows
🍎 macOS / Linux

Windows (PowerShell)

PowerShell # Створити головну папку для проєктів mkdir $HOME\claude-projects # Створити папку для тестів mkdir $HOME\claude-projects\sandbox # Перейти в папку cd $HOME\claude-projects\sandbox
💡
$HOME — це ваша домашня папка, наприклад C:\Users\Іван. PowerShell підставить її автоматично.

macOS / Linux (Terminal)

Terminal # Створити головну папку для проєктів mkdir -p ~/claude-projects/sandbox # Перейти в папку cd ~/claude-projects/sandbox
💡
~ (тільда) — це скорочення для вашої домашньої папки, наприклад /Users/ivan.

Перший запуск та авторизація

🔐 Запускаємо Claude Code вперше

Тепер запустимо Claude Code і підключимо його до вашого акаунту.

  1. Переконайтесь, що ви в робочій папці:
    cd ~/claude-projects/sandbox

    (На Windows: cd $HOME\claude-projects\sandbox)

  2. Запустіть Claude Code:
    claude

    Так, просто одне слово claude — і натисніть Enter.

  3. Відкриється вікно авторизації. Claude Code покаже посилання або відкриє браузер автоматично. Вам потрібно:
    → Увійти в акаунт claude.ai (той самий, де ви оплатили підписку)
    → Натиснути "Allow" (Дозволити), щоб Claude Code міг працювати з вашим акаунтом
  4. Поверніться в термінал. Ви побачите привітання від Claude Code — це означає, що все працює!
✅
Вітаю! Якщо ви бачите інтерфейс Claude Code в терміналі — авторизація пройшла успішно. Тепер можна працювати!
⚠️
Помилка авторизації? Переконайтесь, що:
1. У вас оплачена підписка Pro або Max на claude.ai
2. Ви входите в той самий акаунт, де оформлена підписка
3. Ваш інтернет працює стабільно

⌨️ Корисні команди Claude Code

Ось основні команди, які вам знадобляться:

Команда Що робить
claude Запустити Claude Code в поточній папці
/help Показати довідку (вводити всередині Claude Code)
/clear Очистити контекст розмови
/compact Стиснути контекст (заощадити запити)
Ctrl + C Перервати поточну дію Claude
Ctrl + D Вийти з Claude Code

Часті запитання (FAQ)

💬 Що робити, якщо npm install видає помилку?

Windows: Запустіть PowerShell від імені адміністратора (Win + X → Terminal (Admin)).

macOS/Linux: Додайте sudo перед командою.

💬 Claude Code каже "subscription required"

Переконайтесь, що підписка оформлена на claude.ai, і ви авторизуєтесь тим самим акаунтом. Підписка на console.anthropic.com (API) — це інша підписка.

💬 Як оновити Claude Code до нової версії?

npm update -g @anthropic-ai/claude-code

💬 Чи можна використовувати Claude Code у VS Code?

Так! Просто відкрийте вбудований термінал у VS Code (Ctrl + `) і виконайте claude. Claude Code працюватиме прямо у вашому редакторі.

💬 Скільки запитів можна робити на Pro плані?

Точний ліміт Anthropic не розголошує, але на Pro плані його достатньо для активної роботи протягом дня. Якщо ліміт вичерпано — почекайте кілька годин або перейдіть на Max план.

Автоматичне встановлення

Один скрипт встановить все необхідне: Node.js, npm та Claude Code

Або встановіть вручну за покроковою інструкцією нижче

0 Що потрібно перед початком

  • Комп'ютер з Windows 10+, macOS або Linux
  • Підключення до інтернету
  • Підписка Claude Pro ($20/міс) на claude.ai
  • 15-20 хвилин вільного часу
Якщо у вас вже є Node.js 18+ — можете одразу перейти до кроку 2.

1 Встановлення Node.js

Node.js — це середовище виконання JavaScript, необхідне для Claude Code.

Windows

  1. Перейдіть на nodejs.org
  2. Натисніть зелену кнопку LTS (рекомендована версія)
  3. Запустіть завантажений .msi файл
  4. Натискайте Next до кінця, нічого не змінюючи
  5. Перезавантажте комп'ютер

Перевірка

node --version
# Має показати v18.x.x або вище

macOS (через Homebrew)

# Встановити Homebrew (якщо немає) /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)" # Встановити Node.js brew install node

Ubuntu / Debian

curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash - sudo apt-get install -y nodejs

Fedora / RHEL

curl -fsSL https://rpm.nodesource.com/setup_22.x | sudo bash - sudo dnf install -y nodejs

2 Встановлення Claude Code

npm install -g @anthropic-ai/claude-code
На macOS/Linux може знадобитись sudo перед командою.

Перевірка

claude --version

3 Авторизація

  1. Створіть робочу папку та перейдіть в неї:
    mkdir -p ~/claude-projects/sandbox && cd ~/claude-projects/sandbox
  2. Запустіть Claude Code:
    claude
  3. У терміналі відкриється посилання — перейдіть по ньому в браузер
  4. Увійдіть у свій акаунт Claude (потрібна підписка Pro)
  5. Натисніть Allow — готово!

4 Перший запуск

Тепер Claude Code готовий до роботи. Спробуйте:

claude "Створи файл hello.py з функцією привітання"
Claude Code працює в контексті поточної папки — він бачить всі файли в ній та може їх змінювати.

Поради для ефективної роботи

1. Працюйте в потрібній папці

Claude бачить файли в поточній директорії. Завжди переходьте в папку проєкту перед запуском.

cd ~/my-project && claude

2. Будьте конкретними

Замість "зроби краще" пишіть конкретно що потрібно змінити.

3. Використовуйте CLAUDE.md

Створіть файл CLAUDE.md в корені проєкту з інструкціями для Claude — він читатиме його автоматично.

# CLAUDE.md ## Про проєкт Це веб-додаток на React + TypeScript ## Правила - Пиши код TypeScript - Використовуй функціональні компоненти - Тести обов'язкові

4. Контролюйте зміни

Claude покаже diff перед кожною зміною файлу. Уважно перевіряйте перед підтвердженням.

5. Git інтеграція

Claude працює з git — може робити коміти, створювати гілки, переглядати історію.

Часті питання (FAQ)

Скільки коштує Claude Code?
Потрібна підписка Claude Pro за $20/місяць на claude.ai. Claude Code використовує API, лімітів зазвичай вистачає для активної роботи.
Чи можна використовувати без підписки?
Так, можна використовувати API-ключ замість підписки. Тоді оплата за використання. Встановіть ключ: export ANTHROPIC_API_KEY=your-key
Помилка "command not found: claude"
Перезавантажте комп'ютер після встановлення. Якщо не допомогло — переконайтесь, що npm глобальний шлях є в PATH. На Windows спробуйте: npx @anthropic-ai/claude-code
Помилка "node version too old"
Потрібна Node.js версії 18 або вище. Оновіть Node.js з nodejs.org або використайте nvm: nvm install 22
Claude Code vs claude.ai — в чому різниця?
claude.ai — це чат у браузері. Claude Code — це інструмент у терміналі, який працює безпосередньо з вашим кодом: читає файли, змінює їх, запускає команди. Ідеальний для розробки.
Чи безпечно давати Claude доступ до файлів?
Claude Code показує кожну зміну перед застосуванням і запитує підтвердження. Ви завжди контролюєте, що саме буде змінено. Рекомендуємо працювати в git-репозиторії, щоб легко відкотити зміни.
